## 🚀 Funcionalidades 100% Interactivas Incluidas

1. **Pestañas de Módulos (Ecosistema Integral)**:
   - Permite alternar entre los 5 módulos:
     - *Aula Virtual Interactiva* (con pizarra matemática dinámica en vivo donde se puede dibujar interactivamente).
     - *Biblioteca de Recursos Abiertos (REA)* (con buscador, simuladores PhET y cuadernos descargables).
     - *Tutoría Acompañante* (simulación de chat con IA socrática pedagógica).
     - *Portal Docente y Analíticas* (tablero de métricas formativas y alertas preventivas).
     - *Modo Ligero & Sin Conexión* (simulador de sincronización a USB / Red Mesh local sin datos móviles).
2. **Barra de Accesibilidad Universal (WCAG 2.1 AAA)**:
   - Botón `Texto A+`: Aumenta el tamaño de la tipografía en toda la página.
   - Botón `Contraste`: Activa el modo de alto contraste para personas con baja visión.
   - Botón `Dislexia`: Cambia la tipografía a una fuente adaptada para personas con dislexia.
   - Botón `Leer`: Lector de pantalla con síntesis de voz en español mediante Web Speech API.
3. **Sección Tabla Comparativa**:
   - Comparación detallada entre la *Educación Convencional* y el *Ecosistema AccedeED* con columnas diferenciadas.
4. **Acordeón Interactivo de Preguntas Frecuentes (FAQ)**:
   - Despliegue y colapso fluido de preguntas sobre gratuidad, privacidad infantil y modo offline.
5. **Modales Interactivos**:
   - `Ver Demo`: Simulador interactivo de preguntas y pizarra de clase en tiempo real.
   - `Empezar gratis`: Formulario de registro por roles (Estudiante, Docente, Institución) con validación y confirmación.
   - `Descargar App/Recursos`: Ventana con opciones para descargar APK de Android, guía PWA y paquetes ISO escolares.
6. **Notificaciones Toast**:
   - Avisos flotantes elegantes al realizar acciones (descargas, suscripción al boletín, respuestas interactivas).
7. **Diseño Completamente Responsivo**:
   - Optimizado para pantallas móviles, tabletas, laptops y monitores ultra-wide.
